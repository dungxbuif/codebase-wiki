# Ticket: Uppercase Generated Markdown Filenames

## Problem

CodeWiki's generated wiki contract mixes lowercase Markdown filenames with uppercase convention files, and `init.md` still refers to `index.md` although the canonical entrypoint is `QUICKSTART.md`. This creates naming drift across skill instructions, generated paths, links, plans, tests, and sync behavior.

## Acceptance Criteria

- [x] Every canonical Markdown file generated by CodeWiki uses an uppercase filename while directories remain lowercase.
- [x] `QUICKSTART.md` is the only documented canonical entrypoint; no current instruction requires `index.md`.
- [x] Internal generated links, WikiPlan paths, ignore rules, tests, and docs use the uppercase contract.
- [x] Init and sync migrate legacy lowercase CodeWiki-generated pages only when they contain CodeWiki generated-region markers.
- [x] Unmarked lowercase human-authored pages are preserved.
- [x] Tests, validation matrix, master docs, context, backlog, ADR, and changelog are reconciled.

## Scope

- Skill package and references.
- Rust companion docs/explore/detect/store/core paths and tests.
- Safe legacy generated-page migration.
- Current requirements, architecture, API, ADR, validation, and release docs.

## Approval

Approved directly by the user on 2026-07-14: all generated Markdown filenames should be uppercase.
